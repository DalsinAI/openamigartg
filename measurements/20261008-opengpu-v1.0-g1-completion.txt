OpenRTG integration
-------------------
The v1.0 integration routes exact cases through opengpu.library:
  RectFill/SetRast solid fill      -> FILL
  COMPLEMENT solid rectangle      -> INVERT
  BltTemplate and classic Text    -> TEMPLATE
  plain same-format RTG blits     -> COPY
  ScrollRaster's plain RTG moves  -> COPY through the shared blit path
  unlayered exact area patterns   -> PATTERN

Cases whose v1.0 command cannot reproduce OpenRTG semantics exactly retain
the existing OpenRTG implementation. In particular layered pattern phase,
non-copy minterms, masked CLUT8 writes and patterned/stippled lines stay on
the proven CPU path.
