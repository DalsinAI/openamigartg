# minigl.library's interface, from which library/minigl/gen_api.py makes
# include/libraries/minigl_dispatch.h (the table and the calls programs
# make through it), include/mgl/minigl_calls.h (the calls' prototypes),
# library/minigl/mgl_table.c (the table the library hands out) and
# library/minigl/mgl_static.c (the same calls as functions, for libmgl.a).
#
# "slot" lines are the table's entries after its five header fields, in
# table order: the order and the types are what compiled programs use
# (dispatch ABI 5, 205 entries, 840 bytes), so a line is never moved.
#   slot RETURN | NAME | PARAMETERS
# "call" lines are the functions programs call (gl*, glu*, glut*, mgl*):
#   call RETURN | NAME | PARAMETERS | HOW
# HOW is an entry and its arguments, where CTX is the current context;
# "guard" calls only when there is a current context; "create" makes the
# new context current; "delete" and "glutinit" are written out by the
# generator.
